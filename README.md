# Broken Limb

Static storefront for https://pbarnhart1.github.io/broken-limb/.

`index.html` contains the responsive layout and small photo-gallery script. Product images are stored in `assets/`; they were downloaded from Broken Limb's own Etsy listings. Purchase and contact links lead to Etsy. No build step is required. GitHub Pages publishes the main branch.
